# sim/

Testbenches and the test-vector files they read.

| Testbench | Tests |
|---|---|
| `tb_npu_pe.v` | One PE: signed multiply, accumulation, extreme values |
| `tb_npu_systolic_array.v` | 4x4 array: input skew, one block, results match the golden model |
| `tb_npu_ppu.v` | Bias, scale, rounding at exactly .5, ReLU, clamp to INT8 |
| `tb_npu_regs.v` | AXI4-Lite register reads/writes |
| `tb_mini_npu_top.v` | Whole mini-NPU through AXI4-Lite and AXI4-Stream, one block end to end |

- Vector files (`*.mem`) are generated by `../python/` from the golden model. They are committed, so the simulations run without Python.
- Each testbench writes `results_<tb>.txt` with PASS/FAIL, calls `$finish`, and has a watchdog timeout.
- Run with `vivado -mode batch -source scripts/simulate.tcl -tclargs <tb_name>` or `-tclargs all`.
